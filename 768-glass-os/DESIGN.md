# 768 Glass OS — visual direction

- Premium monochrome palette: graphite, near-black, soft silver.
- No rainbow gradients, saturated neon, or cluttered cards.
- Frosted translucent surfaces with subtle borders and restrained highlights.
- Responsive safe-area layout uses Android safe drawing insets, respecting centred/offset punch-hole cameras, notches, and other display cutouts supported by the device.
- Touch-first navigation, understated typography, and low-amplitude spring motion.
- Android launchers cannot replace Samsung's protected system UI or lock screen.
