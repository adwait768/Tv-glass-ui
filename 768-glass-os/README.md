# 768 Glass OS
Touch-first Android launcher prototype for Samsung Galaxy A17 5G.

## Prototype features
- Glass-inspired home screen and bottom navigation.
- App drawer that launches installed apps.
- Read-only internal storage overview.
- Android Home role so the user can select it as the default launcher.

## Build
Open this folder as an Android Studio project, or use the workflow in .github/workflows/768-glass-os.yml.

## Android boundaries
This launcher does not replace One UI System UI, Quick Settings, lock screen or Samsung Settings. Storage is read-only; cleanup uses Android-supported controls.
